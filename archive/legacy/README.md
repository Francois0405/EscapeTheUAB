# Material archivado

Nada de esta carpeta se compila ni se carga. Se conserva por su posible valor academico o como fuente.

- `vgi-samples/`: ejemplos del entorno VGI (puntos de control de curvas `.crv`, modelos Skull y UH60,
  texturas y tres shaders que solo existen aqui). Se pueden abrir desde los menus VGI.
- `res/`: modelos fuente que no son copia de ningun asset (piezas, pizarra, brazos) y `ui/hand.svg`,
  el original de `assets/ui/hand.png`. Los `.obj` identicos a los de `assets/models/` se eliminaron.

Lo eliminado sigue en el historial; la etiqueta local `backup/pre-cleanup-2026-11-26` marca el estado anterior.
